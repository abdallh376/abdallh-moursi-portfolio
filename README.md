# Abdallh Moursi Portfolio

React + Vite personal portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personal assets to replace

- `public/assets/profile.jpg` — your profile photo (used by the Hero component if configured there).
- `public/assets/Abdallh-Moursi-CV.pdf` — your CV.
- `public/assets/projects/` — project screenshots.
- `public/assets/certificates/` — real certificate images.

Update social profile URLs and the WhatsApp number in the corresponding component files before publishing. Replace testimonial placeholders with genuine reviews.
